# 语言学习

> 对程序员来说，**英语**是最重要的语言——文档、代码、报错信息、技术文章、官方资料基本都是英文。
> 学好英语，等于打开了整个编程世界的大门 🌍

## 为什么学

- 读官方文档（Documentation）不再靠翻译
- 看懂报错信息（Error Message）
- 上国际社区（GitHub、Stack Overflow）交流
- 看英文教程和论文

## 目标（参考）

- [ ] 每天背 20 个单词（Anki / 墨墨背单词）
- [ ] 每天读一篇英文技术短文
- [ ] 能读懂英文报错信息
- [ ] 能用英语在 GitHub 上提问/提 issue

## 每天安排（参考）

| 时间 | 内容 |
| --- | --- |
| 早上 10 分钟 | 背单词 |
| 学习/敲代码时 | 遇到英文报错，尝试自己读懂 |
| 睡前 10 分钟 | 读一篇英文短文 |
