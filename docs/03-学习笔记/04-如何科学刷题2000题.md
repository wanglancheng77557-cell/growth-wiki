# 如何科学地 8 个月写 2000 题（Algo-Atlas 方法论整理）

> 来源：力扣分享帖《如何科学的8个月写2000题 & X-Plore》（作者 lvyneko）+ 开源项目 [Algo-Atlas](https://github.com/lvy010/Algo-Atlas)

## 核心理念

- 亲测：**0 基础**只要科学计划，完全可以入门
- 核心方法论分三步：**系统搭框架 → 定期复习 → 刷题练习**

## 第一步：系统搭框架

把网上丰富的学习资源（网课 + 博客 + 资料）**系统整理成一份自己的笔记框架**。

> 有了自己的框架之后，刷题时大脑可以自动归档。

参考分类体系：
- 100 道典型例题
- 递归、搜索与回溯
- 动态规划
- 贪心算法
- 双指针 / 滑动窗口 / 前缀和 / 位运算
- 栈 / 队列+BFS / 优先队列
- 图、拓扑排序 等

**学习顺序：递归 → 搜索 → 回溯**
（搜索是递归中的一个分支，回溯是搜索中的一个分支）

## 第二步：定期复习

定期回顾学过的内容，防止遗忘，把短期记忆变成长期掌握。

## 第三步：刷题练习

- **写代码前**：先模拟代码，把例子在纸上/脑里走一遍（如 N 皇后）
- **写代码后**：梳理代码，提炼关键状态和思路（如正则表达式匹配）

**动态规划心法：**
> 动态规划最核心的思想，就在于「拆分子问题，记住过往，减少重复计算」。
> 0 基础可以先从最简单的题（如第 N 个泰波那契数）建立直觉。

## 好用的笔记工具

- **Typora**（Markdown 笔记，她推荐直接用）
- **draw.io**（画图）
- **xmind**（思维导图）
- **Goodnotes**（手写/平板）
- **LICEcap**（录屏做动图）

## 使用指南（开源）

- `git clone` 到本地，用 Typora 打开，可以直接对源 `.md` 文件做自己的批注
- 所有笔记 & 代码均为开源，支持自由获取 / 引用 / 改造，二创可以 fork 一份
