# 我的两年学习路线图（Python 起步 → C 深入）

> 参考：lvyneko《2000h+ 计算机自学分享》的「古法」路线（C 语言打底 → 数据结构算法 → 刷题 → 计算机基础）
> 我的调整：**高中接触过 Python → 先用 Python 刷题（上手快）→ 边学边刷 → C 掌握后切到 C 刷题**
> 方法照搬她的：**系统搭框架 → 定期复习 → 刷题练习**

## 总体思路

- 本科两年（2026.9 开始），跟着学校课程 + 自学并行
- **Python 先刷题**：熟悉语法、思路快，先建立「会做题」的信心
- **C 后深入**：C 是本科核心（指针、内存、数据结构），必须掌握，掌握后刷题切 C（一道题 Python 想思路 + C 写一遍 = 一题两刷，收益最大）
- 所有笔记记进成长 Wiki，每周复盘、每月总结

## 阶段安排

### 阶段 0：开学前（现在 → 2026.9）
- 复习 Python 基础：变量、循环、函数、列表、字典、类
- 搭算法框架：按 Algo-Atlas 的分类建自己的笔记框架（双指针 / 滑动窗口 / 栈 / 队列 / BFS / 递归 / DP…）
- 开始用 Python 刷 LeetCode 简单题（每天 1~2 题）
- 用 Typora / Obsidian 记笔记，整理进 wiki

### 阶段 1：第一学期（2026.9 – 2027.1）
- Python 刷题：简单 → 中等，按框架分类刷（从「100 道典型例题」起步）
- 数据结构（用 Python 先理解）：数组、链表、栈、队列、树、图、哈希表
- 学校课程若有 C，跟着学 C 基础：变量、函数、数组、指针
- 每周复盘 + 每月总结（写进 wiki 的成长记录）

### 阶段 2：寒假 + 第二学期（2027.2 – 2027.7）
- C 语言深入：指针、动态内存、结构体、链表/树用 C 实现（参考 Algo-Atlas 的 c++ deep tutorial）
- 刷题逐渐切到 C：同一道题「Python 想思路 + C 写一遍」
- 学一点 C++ 面向对象（类、继承、多态），为以后铺路
- 目标：LeetCode 累计 300+ 题

### 阶段 3：大二（2027.9 – 2028.6）
- 计算机基础四件套：操作系统 / 计算机网络 / 计算机组成原理 / 数据库
- 继续刷题（C / C++），从中等迈向困难
- 做 2~3 个自己的小项目（挂到 wiki 的「我的项目」页）
- 按兴趣定方向：后端 / AI / 嵌入式……

## 每天怎么安排（参考）

| 时间 | 内容 |
| --- | --- |
| 60~90 分钟 | 上课 / 看教程（C 或数据结构） |
| 60 分钟 | 刷题 1~2 道（先自己思考 15 分钟，再看题解总结） |
| 15 分钟 | 把今天学的、踩的坑记进 wiki |
| 每周日 | 复盘一周，更新成长时间线 |

## 工具清单

- 笔记：Typora / Obsidian + 成长 Wiki
- 刷题：LeetCode（先用 Python，后切 C）
- 代码模板：Algo-Atlas 里的 `templates`
- 路线参考：Algo-Atlas `README.md` 的分类顺序
